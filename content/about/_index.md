## Profile

甘肃天水，黄土高原上一个小农村，三十多户人家。这里的冬天很长，但四季分明，远山的轮廓在晴天里清晰得像是修剪出来的。

<!--{{ figure(src="/img/home.webp", alt="我的社会化的启蒙地", caption="我的社会化的初始地") }}-->

恰逢千禧年，我在这里出生，在这里长大，现在还在这里。勉强算一个过度思考者，计算机硕士在读。

{% quote(cite="塞缪尔·约翰逊《漫步者》") %}
从作者的著作转向与他的交谈之时，往往就像是远眺之后，突然闯入一座大城市。远远望去，我们只看见寺庙的尖顶和宫殿的塔楼，便以为那里是辉煌、宏伟与壮丽的居所；但一旦穿过城门，却发现街道狭窄曲折，破旧的茅屋随处可见，障碍重重，烟雾缭绕。
{% end %}

### Technology

在资本和技术的时代，人们大概是疯了，我也一样。

海德格尔说：「尼采最后体会到无家可归的味道。尼采在形而上学的范围内找不到摆脱无家可归的痛苦的其他出路，只有把形而上学倒转过来，但这却是无出路状态的完成。」我们现在的人如尼采一般，也遭遇了虚无。我们用范畴、概念去规定自然界，好让它更好地为资本增殖服务，技术实现了这一点。这种关系中没有任何精神维度，但人却是精神性的存在。在这个强制进步的时代，我们没有做人的感觉。我们的出路在哪里？尼采要重估一切价值，却没有完成；海德格尔走了一段，也已精疲力尽。回归感性，领会存在，但这非常难，就像普通人去领会佛学所说的「空」，有的人顿悟，但大多数人被范畴思维、概念思维重重裹挟，很难领会。存在也是如此。有人说，存在如同鼻子尖上的东西，一直在我们眼前，却总是最后才被发现。

## Bents

{% quote(cite="弗洛姆《为自己的人——伦理心理学探究（1947年）》") %}
人的问题只有一种解决办法，即面对事实：承认在一个不关心他的命运的宇宙中，他根本上就是孤独的，认识到能为他解决问题的超越他的力量是没有的。如果他面对这个事实而不恐慌，他就会认识到：人除了发挥自己的力量，即通过过生产性的生活赋予他的生活以意义之外，对生活便加不上任何意义。
{% end %}

在业余时间，除了哲学方面的东西，我还喜欢欣赏诗歌。哲学是对思想的思想，而诗歌保护了文字的命名力量，可我时常要写论文，厌烦得紧，因为那不过是在消耗文字。

运动方面我喜欢跑步，打羽毛球、网球和乒乓球。喜欢一个人在夜晚去公园散步，我很喜欢这种环境，外界的干扰很少，只有零星几盏昏暗的路灯，行人也都看不清表情，走着走着，很容易就进入了心流。

除了运动之外，我也喜欢一些需要动手、容易让人专注的事情，比如玩魔方，写写字，折腾 Linux 服务器。

听歌的话，全看心情，忧郁的时候听着忧郁的歌，开心的时候听着开心的歌，颓废的时候听着颓废的歌，焦虑的时候听不进去歌，就这样，什么抓耳朵就听什么，此外我还爱听秦腔，可能是年龄到了就自动解锁了吧。也喜欢翻翻好看的写真集。

不善于网络对话，喜欢和朋友面对面地深度交流，可以聊一晚上。
